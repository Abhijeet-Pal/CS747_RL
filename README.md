# CS747: Foundations of Intelligent and Learning Agents

This repository contains my solutions to the programming assignments for **CS747: Foundations of Intelligent and Learning Agents** at **IIT Bombay**.

## Assignments

### Programming Assignment 1 — Multi-Armed Bandits
Implemented and analyzed several stochastic bandit algorithms, including **UCB**, **KL-UCB**, and **Thompson Sampling**, along with extensions for noisy and multiple-bandit settings.

📁 `Programming_Assignment_1/`

---

### Programming Assignment 2 — MDP Planning
Implemented classical **Markov Decision Process (MDP)** planning algorithms, including **Value Iteration**, **Howard's Policy Iteration**, and **Linear Programming**. Also modeled a **2v1 football game** as an MDP and computed optimal strategies.

📁 `Programming_Assignment_2/`

---

### Programming Assignment 3 — Optimal Cue-stick Control
Designed an autonomous billiards agent that selects optimal cue angles and forces to pocket all balls under stochastic shot execution.

📁 `Programming_Assignment_3/`
