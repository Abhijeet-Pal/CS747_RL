# Multi-Armed Bandits (CS747 Programming Assignment 1)

This repository contains my solution for **Programming Assignment 1** of **CS747: Foundations of Intelligent and Learning Agents** at IIT Bombay.

## Overview

The assignment focuses on implementing and analyzing algorithms for the **stochastic multi-armed bandit** problem with the objective of minimizing cumulative regret under different bandit settings.

## Implemented Tasks

- **Task 1:** Implemented **UCB**, **KL-UCB**, and **Thompson Sampling** algorithms.
- **Task 2:** Studied the effect of arm mean distributions on regret through empirical analysis and generated comparison plots.
- **Task 3:** Designed an algorithm for **faulty/noisy bandits**, where arm pulls return incorrect observations with a known probability.
- **Task 4:** Developed an algorithm for a **multiple-bandit** setting, where each pull is randomly assigned to one of two bandit instances.

## Repository Contents

- `task1.py` – UCB, KL-UCB, and Thompson Sampling implementations.
- `task2.py` – Regret analysis experiments and plotting.
