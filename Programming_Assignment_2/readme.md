# MDP Planning and Football Strategy (CS747 Programming Assignment 2)

This repository contains my solution for **Programming Assignment 2** of **CS747: Foundations of Intelligent and Learning Agents** at IIT Bombay.

## Overview

The assignment focuses on solving **Markov Decision Processes (MDPs)** using classical planning algorithms and applying them to compute optimal strategies for a simplified **2v1 football** scenario.

## Implemented Tasks

- **Task 1:** Implemented **Value Iteration**, **Howard's Policy Iteration**, and **Linear Programming** for solving finite MDPs, along with policy evaluation.
- **Task 2:** Modeled the 2v1 football game as an MDP by implementing an encoder and decoder to compute optimal policies using the planner.
## Repository Contents

- `planner.py` – MDP planning algorithms and policy evaluation.
- `encoder.py` – Converts the football game into an MDP.
- `decoder.py` – Converts the planner output back into a football policy.
- `report.pdf` – Report describing the implementation and experimental analysis.
